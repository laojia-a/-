# 《JCLAW TV · 工作频道》创作思路

## 1. 核心创意

这次介绍的不是一个工具，而是一组工具。七个仓库的关系是：

| 仓库 | 片中身份 | 位置 |
|---|---|---|
| `laojia-a/home` | JCLAW TV：复古电视外形的导航首页，有机身旋钮、开关/暂停/设置三键和七个频道 | 贯穿全片的主角，也是目录和导航 |
| `laojia-a/1-git-2-cloudflare` | 临床工具集（cth.jclaw.top） | CH01 |
| `laojia-a/training-factory` | 临研知视（cv.jclaw.top） | CH02 |
| `laojia-a/be-workbench` | BE Workbench（be-workbench.jclaw.top） | CH03 |
| `pharmaxi/EZCTD` | 临床 CRO 本机 PDF 工作台 | CH04 |
| `laojia-a/BE-Solo` | BE Solo（be-solo.jclaw.top，私有访问） | CH05 |
| `pharmaxi/be-csr-review` | BE 报告审核 Agent Skill（不是网站，不在电视频道表里） | 特别节目 |

所以全片按一档电视节目来拍：开机、换台、每个频道一段节目、插播一档特别节目，最后关机。home 是目录和导航，片子的结构也照着它来，观众看完就知道真实产品怎么用：转旋钮换频道，点屏幕进入工具。

**一句话**：工具散落在几十个标签页里，JCLAW TV 让你转一下旋钮就换一件工作。

## 2. 和上一部《BE CSR Review》比，强在哪里

| 维度 | BE CSR Review | 本片 |
|---|---|---|
| 叙事 | 单产品功能顺序讲解 | 有主角物件（电视）和贯穿动作（开机→换台→插播→关机），首尾呼应 |
| 视觉材质 | 全片同一种蓝青 HUD | 每个频道一种材质与调色：暖纸书桌 / 墨绿黑板与芝士黄卡片 / 深青三维数据空间 / 豆沙紫的 PDF 灯箱 / 靛蓝玻璃界面；特别节目回到上一部的青蓝 HUD 作为致敬；片头片尾是暗室里只有屏幕发光的低调光 |
| 空间 | 2.5D 平面 | 透视贴图引擎：所有卡片、界面、电视机身先 2D 绘制再映射到 3D 平面，可做环绕、俯冲、穿屏 |
| 后期 | bloom + 光条 + soft-light 调色 | 逐像素调色：胶片影调曲线、分离色调、径向色差、晕光、彩色颗粒、抖动去色带；快速运镜开 180° 快门运动模糊；片门抖动 |
| 转场 | 淡入淡出为主 | 有语义：CRT 开机线、换台雪花与滚动条、穿进屏幕、信号锁定、插播条、CRT 关机收点 |
| 声音 | D 小调合成配乐 | 120 BPM 混合预告片配乐，每个频道换配器；冲击后骤停；CRT 啸叫、电流嗡、旋钮咔哒、静电噪声等拟音；磁带饱和、中/侧展宽、响度母带 |
| 时长 | 98 s | 160 s |

## 3. 结构（120 BPM，一拍 0.5 s）

| 时间 | 段落 | 画面 | 声音 |
|---|---|---|---|
| 0–10 | 冷开场 | 全黑，开关键上的绿灯亮起；CRT 开机：一条白线展开成屏幕，屏幕上是七色测试卡（七条色带就是七个频道的主题色）；暗室里电视是唯一光源，尘埃在光里漂 | 房间底噪、电流嗡、开机“砰”、高频啸叫 |
| 10–24 | 风暴 | 推进雪花，雪花变成上百个窗口：表格、合同、计算器、课件、PK 曲线、排期、PDF……越飞越快，22 s 全部砸向镜头，黑场骤停；黑暗中一声旋钮咔哒 | 加速的滴答与上行音，冲击后完全静音 |
| 24–36 | 片名 | 电视产品英雄镜头：旋钮金属纹路特写，拉开为 3/4 全景，片名落版；屏幕显示节目单；旋钮转到 1，镜头穿进屏幕 | BRAAM + 次低频，主题动机首次出现 |
| 36–52 | CH01 临床工具集 | 暖纸书桌上一路横移：合同分期与中文大写、采血管落架、例数曲线、高脂餐热量表、CTCAE/MedDRA 卡片、Cloudflare 同步 | 暖色拨弦 + 轻打击 |
| 52–66 | CH02 临研知视 | 墨绿黑板空间，芝士黄课程卡片飞入排成学习路径；版本锁定；学员进度环只增不减 | 卡林巴、粉笔声 |
| 66–88 | CH03 BE Workbench | 深青三维空间：数据识别与 QC、冻结快照、三维浓度–时间曲线穿行、AUC 扫描、90% CI 落入 80–125% 走廊（示例数据，不给等效结论）、三种数据身份分流 | 太鼓、合成低音，CI 落定时 BRAAM 主冲击 |
| 88–104 | CH04 EZCTD | 雪花 → 信号锁定；PDF 页面在灯箱上展开：检索命中高亮、26 条规则逐条亮出状态、原件加锁、独立副本生成并复验 | 冷静的脉冲与纸页声 |
| 104–120 | CH05 BE Solo | 靛蓝玻璃界面：16 个节点进度、14 天事项密度、Issue/To-do；BE 助手起草卡片 → 待审核 → 人点“接受” | 脉冲琶音 |
| 120–134 | 特别节目 BE CSR Review | “特别节目”插播条切入；回到上一部的青蓝 HUD：G0–G5 六道关口、表格逐格核对、七列意见表 | 插播提示音 + 上一部的冲击音色 |
| 134–160 | 收束 | 屏内快速换台回放 → 穿出屏幕回到暗室 → 光束从屏幕射向各个入口并汇入 www.jclaw.top → 片名与标语 → CRT 关机收成一个亮点 → 绿灯 | 全编制主题动机转大调，最后一击后关机声，回到底噪 |

每段高潮后接反向段落：风暴之后骤停，片名之后转入安静的 CH01，CH03 的高潮之后是克制的 CH04，收束的大场面之后以关机和一颗绿灯结尾。

## 4. 内容边界

- `laojia-a` 的五个源仓库是**私有**的，而成片发布到公开仓库：片中不使用真实截图、真实项目名、账号、密钥或资源 ID；界面按真实布局用代码重绘，数据是演示示例，画面上标注“示例数据”。
- `pharmaxi/be-csr-review` 在本次环境中无法访问（GitHub 返回 404），特别节目的内容只采用上一部宣传片里已经公开的表述（G0–G5、逐格核对、七列意见表、辅助审核不替代专业判断）。
- 只讲各仓库 README 中已有的能力，沿用它们的克制口径：BE Workbench 只出现 90% CI 示意，不出现“等效/通过”结论；EZCTD 的 PASS 只是本地有限检查，不是官方通过；BE 助手只起草，由人接受或拒绝；临研知视进度只增不减、课程版本固定；CTCAE 只查询不自动分级。
- home 当前的 CH04、CH05 在首页上仍显示无信号；片中用“雪花 → 信号锁定”表现它们，不说成已经接入首页。EZCTD 是本机工作台，没有网址。
- 片尾小字：工具用于辅助计算与管理，不替代专业判断与监管结论；片中数据均为演示示例。
