# JCLAW TV · 工作频道 — 宣传片 / Promo film

`video/jclaw-tv-promo.mp4`: 160 s, 1920×1080, 30 fps, H.264 (CRF 16) with AAC 320k audio, 2.39:1 letterbox, burned-in zh + en subtitles.

The film presents the JCLAW TV tool suite as one TV programme. [home](https://github.com/laojia-a/home) is the retro TV navigation page, and it is both the table of contents and the main character of the film. The dial switches between channels: Clinical Toolkit, Clinical Vision, BE Workbench, EZCTD and BE Solo. BE CSR Review appears as a special programme. The creative brief, the comparison with the previous BE CSR Review film and the content boundaries are in [TREATMENT.md](TREATMENT.md).

## Rebuild

Requirements: Node 20+, Python 3.10+ with `numpy` and `scipy`, and `ffmpeg` (or set `FFMPEG=/path/to/ffmpeg`, `PYTHON=/path/to/python`).

```bash
cd jclaw-tv-promo
npm install          # @napi-rs/canvas (Skia)
npm run fonts        # downloads the OFL fonts into fonts/ (gitignored)
npm run build        # soundtrack + all frames -> video/   (≈15 min on 8 cores)
```

- `node src/render.js --preview 28.4,82.6` writes stills to `build/preview/`.
- `node src/render.js --sheet 36.5,52.5,66.5 --name s1` writes a contact sheet.
- `node src/render.js --range 66,88` renders one section with its sound to `build/range.mp4`.
- `npm run audio` renders only the soundtrack to `build/soundtrack.wav`.

## Code map

| 文件 | 作用 |
|---|---|
| `src/timeline.js` | Single source of truth: scene boundaries, key moments, subtitles, camera impulses and motion-blur ranges. The audio script reads the same file. |
| `src/lib.js` | Math, easing, noise, 3D camera, perspective-correct texture mapping onto 3D planes, and text helpers |
| `src/post.js` | Multi-scale bloom, halation, anamorphic streaks, and a per-pixel film grade (filmic curve, split toning, radial chromatic aberration, vignette, chroma grain, dither). Also the TV static. |
| `src/tv.js` | Procedural model of the home S10 TV: knob 1–7, CH display, power/pause/settings keys, speaker, handle, antennas, CRT power-on/off |
| `src/frame.js` | Compositor: 180° shutter motion blur, shake and gate weave, post-processing, letterbox, subtitles |
| `src/scenes/*.js` | One file per section. Each scene is a pure function `(ctx, localTime)` |
| `audio/score.py` | Synthesized score and sound design (Karplus-Strong plucks, kalimba, felt keys, taiko, braams, risers, CRT whine, static, knob clicks), convolution reverb, tape saturation, mid/side width, BS.1770 loudness at −16 LUFS, 4× oversampled true-peak limiter at −1.2 dBTP |
| `src/render.js` | Parallel workers → x264 segments → concat → mux; writes the SRT and the poster |

## Notes

- Five of the source repositories (`laojia-a/*`) are private, while this repository is public. For that reason the film uses no real screenshots, project names, accounts, keys or resource IDs. The interfaces are redrawn in code from the real layouts, all values are demo data, and the screens carry a "示例数据 · DEMO DATA" tag where relevant.
- Claims are limited to what each README states, using the same cautious wording. BE Workbench shows 90% CIs with no equivalence verdict. EZCTD's PASS is a limited local check, not an official pass. BE Solo's assistant only drafts and a person accepts. Clinical Vision's progress only goes up and course versions are pinned. CTCAE is look-up only, with no automatic grading.
- On the live home page, CH04 and CH05 still show no signal. The film shows this as "static → signal lock" and does not claim they are wired into the TV yet. EZCTD is a local workbench and has no URL.
- `pharmaxi/be-csr-review` could not be read from the build environment (GitHub returned 404). The special programme reuses only the wording already published in the previous BE CSR Review promo.
- Fonts (SIL OFL 1.1, not committed): Noto Sans SC, Noto Serif SC, Inter, Anton, Cormorant Garamond and JetBrains Mono.
- `@napi-rs/canvas` is pinned to 0.1.88. In 0.1.92–0.1.100, drawing a canvas onto another canvas leaks one full bitmap per call, so a render runs out of memory within a few seconds of film.
- The 2-pass delivery encode (≈4.2 Mbit/s, under GitHub's 100 MB limit) is made from the CRF-16 master in `build/`. The commands are in `scripts/deliver.sh`.
- No source code in any of the featured repositories was modified.
