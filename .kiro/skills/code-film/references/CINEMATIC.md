# 电影质感：好莱坞大片 vs HBO 剧集

“质感”= 一致的视觉/声音规则 × 克制。下面把两种风格拆成可执行的规则，以及在本引擎里的写法。

## 1. 对照表

| 维度 | 好莱坞大片（预告片/史诗） | HBO 顶级剧集（《切尔诺贝利》《继承之战》式） |
|---|---|---|
| 画幅 | 2.39:1 变形宽银幕 | 2.0:1 或 16:9，构图留白多 |
| 色彩 | 青橙互补：暗部青蓝、肤色/高光橙；饱和略高 | 去饱和、偏冷或偏暖的单一主色；色彩只用来表达情绪 |
| 影调 | 高对比、高光柔和滚降、黑位纯净 | 低调光（low-key）、大面积暗部、黑位略抬（不死黑） |
| 光 | 强逆光、轮廓光、镜头光条、体积光 | 动机光源：画面里看得见的灯/窗决定光从哪来；单侧光 |
| 镜头 | 广角大景、英雄仰角、缓慢推近揭示 | 中近景、偏离中心构图、浅景深、前景遮挡 |
| 运镜 | 平滑大幅推拉摇移、航拍感 | 极慢推（几乎察觉不到）、轻微手持呼吸 |
| 剪辑 | 节奏加速、冲击剪、黑场停顿 | 长镜头、让沉默持续、少转场 |
| 字体 | 衬线大写、宽字距、缓慢收紧 | 小号无衬线或细衬线、低调、居左 |
| 声音 | BRAAM、次低频冲击、上行弦乐、合唱、骤停 | 环境声为主（房间底噪、雨、远处城市）、低音长音、稀疏钢琴、大量留白 |
| 混音 | 动态大，冲击前压静 | 对白清晰优先，音乐压得很低 |

## 2. 引擎参数（`render/presets.js`）

| 参数 | 作用 | 大片 | HBO |
|---|---|---|---|
| `filmic` | ACES 胶片影调曲线（高光柔和、不爆） | .8–.9 | .9 |
| `split` / `shadowTint` / `highTint` | 分离色调：暗部与高光分别加色 | .5–.6，暗青高橙 | .3–.4，轻微冷暗 |
| `streak` / `streakTint` | 变形镜头横向光条（只在高光处出现） | .5–.9，蓝色 | 0 |
| `halation` | 胶片晕：高光边缘的红橙光 | .15–.25 | .1 |
| `bars` | 遮幅比例（2.39 / 2.0 / 0=无），字幕自动上移 | 2.39 | 2.0 |
| `weave` | 胶片片门抖动（24fps 量化的微小位移） | .4–.5 | .3 |
| `black` | 黑位抬升 | .01 | .025–.03 |
| `grain` / `grainSize` | 颗粒强度 / 颗粒大小（>1 更像胶片） | .03 / 1.6 | .045 / 1.4 |
| `sat` / `con` | 饱和 / 对比 | 1.05 / 1.08 | .78 / 1.02 |
| `bloom` / `thr` | 泛光量 / 阈值 | .55 / .7 | .22 / .85 |

同一场景内情绪变化：`post: (S) => mixP(P.hollywood, P.trailer, k)`。

## 3. 画面写法

**大片**
- 天空做冷色渐变、地平线和光源做暖色：配色本身就是青橙对比，后期只是加强。
- 一个强光源（太阳/爆点）放在画面里，配 `streak` 产生光条；多层山/建筑剪影做大气透视（越远越亮越蓝）。
- `cam(c, t, dur, { push: .08–.15 })` 缓推；标题用宽字距衬线大写，随时间字距收紧 + 淡入。
- 高潮：`P.trailer` + `hit_add(sfx_braam)` + `silence_after()`。

**HBO**
- 先决定画面里的光源（台灯、窗、屏幕），所有亮部都来自它们；其余区域保持暗。用 `godRays` 做窗光，`motes` 让光束里的尘埃可见。
- 人物用剪影 + 一条细轮廓光（来自窗外冷光），比画出五官更有质感。
- 前景放一块虚化的暗物体（门框、椅背）：`depthLayer(c, fn, 12–16)`，立刻有纵深。
- `cam(c, t, dur, { push: .03–.06, drift: .6–1 })`：慢到几乎看不出的推近 + 呼吸感。
- 文字少、字号小；章节卡可保留，但别用故障转场。
- 声音：环境声（`amb_room`、`amb_rain`）是质感的一半；音乐用低音弦乐长音 + 稀疏钢琴。

## 4. 常见失败

- 所有效果都开满：光条、故障、色差同时出现 = 廉价感。每个场景只突出一种手段。
- 亮底开高泛光：纸张/白屏糊成一片。
- 青橙调用在没有暖色元素的画面上：只会变成整体发青。
- 遮幅后字幕仍在最底部：本引擎已自动上移；自己画的底部文字要避开遮幅区域。
- HBO 风格配大片音乐：画面克制、声音浮夸，质感立刻崩。
