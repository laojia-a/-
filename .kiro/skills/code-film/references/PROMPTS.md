# 提示词

把 `【】` 换成你的内容。前 3 个可以给任何大模型用；4–7 是给能读写代码的 AI 助手（如 Kiro）用的，让它直接在本模板里干活。

---

## 1. 选题与叙事策划

```
你是一位纪录片导演兼知识类视频策划，擅长把专业话题做成有电影感的 B站视频。
题目：【AI 对 XX 工作的影响，过去与未来】，目标时长【8–10】分钟，观众是【该行业从业者和感兴趣的大众】，署名【支线进行中】。

请给出 3 个不同的叙事设定（谁来讲、从哪个时间点讲），每个都要：
1. 一个特殊叙述者（例如未来的 AI、一件物品、一个机构），说明它为什么能同时讲过去和未来；
2. 一个贯穿全片的小人物，开头出现，结尾回归，形成闭环；
3. 一个开场悬念数字（必须是真实、可查证的数据），在中段揭晓；
4. 一句结尾“可以带走的话”，最好能自然落到署名上；
5. 一条情绪曲线：每段的情绪，以及高潮后的反向段落。
最后推荐一个设定，并说明理由。
```

## 2. 史实与数据研究

```
为下面的视频大纲整理事实依据：【粘贴大纲】
要求：
- 每个年份、数字、事件给出原始来源（论文/官方文件/权威媒体）和链接；
- 标注确定程度：已证实 / 有争议 / 需核实；
- 找出 6–10 个“硬数字”，每个注明用于哪一章；
- 指出大纲里任何不准确或夸大的说法，给出更准确的表述；
- 区分“已发生”和“推演”，推演部分写明依据的现实趋势。
```

## 3. 逐句台词（直接生成 lines.py）

```
根据以下大纲和事实，写成逐句旁白，并输出为 Python 的 SCENES 列表（格式见下方示例）。
规则：
- 每句 ≤ 40 字，只讲一件事；口语、可朗读；数字写成中文读法放在 tts，阿拉伯数字放在 sub；
- 每个场景 2–6 句；有章节卡的场景 lead=2.8；
- post 停顿：陈述 0.4–0.6、段落结束 0.8–1.2、爆点前 1.2–1.6、爆点后 2–2.5；
- 长句在 sub 里用 \n 分成两行；
- 角色：narrator（主叙述者）、【其他角色】；英文引文放 sub_en。
- 全片总字数控制在【1800–2200】字。
示例格式：【粘贴 script/lines.py 的 SCENES 示例】
大纲：【粘贴】
```

## 4. 分镜与视觉设计（给代码助手）

```
读 script/lines.py 和 build/timeline.json。为每个场景写一份分镜：
- 材质与后期预设（从 render/presets.js 选或新建）；
- 每句台词对应的画面动作，精确到“第几句开始后几秒”；
- 用到 render/scenes/lib.js 里哪些组件，需要新做哪些；
- 转场类型（按 references/PLAYBOOK.md 的语义）；
- 哪些时刻需要 glitch / flash / 骤停。
输出成表格，先不要写代码，等我确认。
```

## 5. 写场景代码（给代码助手）

```
按确认后的分镜，在 render/scenes/ 下写场景代码，遵守 README 的“场景代码约定”（纯函数、用 S.L() 对齐台词、随机用 rng/ihash、亮底高阈值）。
每写完一章就用 `node render/render.js preview` 给每个场景出 3 张静帧（开头/中段/结尾），拼成联系表给我看，并自查：文字出框、重叠、泛光糊白、字幕遮挡。确认后再写下一章。
```

## 6. 配乐与音效（给代码助手）

```
读 timeline.json 和分镜，在 audio/cues.py 里为每个场景写配乐、在 audio/sfx.py 里写音效：
- 主题动机：【小调旋律或让你设计】，首次出现在【场景】，结尾转大调；
- 每章配器跟材质走（参考 references/PLAYBOOK.md）；
- 爆点用 hit_add + silence_after；音效时间点与画面代码用同一表达式；
- 跑 score.py / sfx.py / mix.py，再用 audio/analyze.py 输出各场景响度，确保旁白比音乐高 13–16dB、全片约 −16 LUFS，告诉我哪里不平衡。
```

## 7. 审片（给代码助手）

```
按 references/PLAYBOOK.md 的审片清单检查成片：从成片每个场景抽 2 帧、每个转场前后各抽 1 帧拼联系表；
检查爆点处声画是否同帧；输出问题清单（按严重程度排序）和修改方案。你看不到动态和听不到声音的部分，明确列出来让我人工检查。
```

## 8. 封面与发布

```
为这部视频设计 B站封面（1920×1080 和 1146×717 两版）：一个视觉主体 + 主标题 ≤ 6 字 + 副标题 ≤ 12 字 + 一个数字角标。
再给出：3 个标题（≤ 40 字，含钩子）、分区、10 个标签、带章节时间戳和资料来源的简介、一条置顶评论。
```

## 9. 指定电影质感（给代码助手，可附在 4、5 号之后）

```
整片视觉按【HBO 剧集 / 好莱坞大片 / 两者结合：日常段 HBO、高潮段大片】处理，遵守 references/CINEMATIC.md：
- 每个场景先写明动机光源、色彩主调、景别、运镜（cam 的 push/drift）、遮幅比例；
- 后期从 P.hbo / P.hollywood / P.trailer / P.noir 起步，用 mixP 做场景内情绪渐变；
- 每个场景只突出一种强手段（光条、故障、闪白三选一）；
- 配乐与音效风格和画面一致（HBO：环境声+低音长音+稀疏钢琴；大片：上行弦乐+合唱+BRAAM+骤停）。
出静帧联系表时，对照 CINEMATIC.md §4 常见失败逐条自查。
```
