# 导演手册

## 1. 叙事模板（9 段）

| 段 | 时长 | 要点 |
|---|---|---|
| 冷开场 | 20–40s | 特殊叙述者自我介绍 + 抛出一个悬念数字，不解释 |
| 人物锚点 | 20–30s | 一个具体的人、一个具体的夜晚；留一句“我们最后还会见面” |
| 片名 | 5–7s | 冲击音 + 切片拼合标题 |
| 历史 1–3 章 | 各 30–60s | 每章一个硬数字 + 一种情绪；每条事实要有来源 |
| 爆点章 | 40–50s | 揭晓开头的数字：铺垫 → 冲击 → **骤停** → 解释 |
| 现实章 | 40–60s | 最近 2–3 年事件，结尾“你在这里” |
| 推演章 | 60–90s | 明确标注“推演”；节奏最快、视觉最炫 |
| 反转章 | 30–40s | 高潮后立刻收到最小的人性细节（一个签名、一条走廊） |
| 闭环 | 20–30s | 人物回归 + 一句可带走的话 + 署名落点 + 评论区提问 |

原则：**每次高潮之后接一个反向的段落**（宏大→安静，快→慢）。一句台词只讲一件事。数字比形容词有力。

## 2. 材质：每个时代一套视觉

给每章定一个“材质”（HUD、羊皮纸、黑白档案、像素游戏、终端、合成波、走廊……），并配一个后期预设。贯穿全片保留一套统一的叙述者标记（HUD 角框、引线标签、等宽数字），让观众始终知道是谁在讲。

## 3. 后期规则

| 参数 | 平时 | 何时加大 |
|---|---|---|
| bloom / thr | 0.45 / 0.78 | 发光元素多时 0.8+/0.6；**亮底（纸、白屏）必须 thr ≥ 0.9、bloom ≤ 0.3**，否则糊白 |
| ca 色差 | 0.0016 | 故障时自动 ×8 |
| grain 颗粒 | 0.035 | 档案/回忆 0.06–0.1 |
| sat / tint | 1 / 中性 | 历史去饱和；情感段渐暖 |
| glitch | 0 | **只用于信息冲击**，全片不超过 5–6 次 |

转场语义：black=时代/章节跳跃；cross=同一时空连续；white=视角/意识切换；glitch=冲击、进入非真实。每章开头放章节卡（2.8 秒）。

## 4. 声音规则

- 一个主题动机贯穿：首次出现在人物锚点，反转章再现，结尾转大调。
- 配器跟时代：古代竖琴/大提琴，近代弦乐/钢琴，游戏段芯片音，现代合成器，高潮全编制+合唱+太鼓。
- 爆点用 `hit_add(braam + impact)` + `silence_after()`：冲击后的寂静最震撼。
- 旁白时音乐压低约 9dB（mix.py 自动）；音乐整体比旁白低 13–16dB。
- 音效时间点与画面代码用同一个表达式。

## 5. 配音规则（《监查者》最大的教训）

- **先定配音，再做其他**。配音不行，后面全部白做。
- 用 ElevenLabs 时带前后句上下文；中文选母语音色；stability 0.4–0.55。
- 停顿：陈述句 post 0.4–0.6，段落结束 0.8–1.2，爆点前 1.2–1.6、爆点后 2–2.5。
- 不要为了纠正读音乱加逗号；用 ElevenLabs 就直接写规范中文。

## 6. 审片清单

- [ ] 配音完整听过一遍，读音、语气、停顿都对
- [ ] 每个场景至少 3 张静帧看过：开头、中段、结尾
- [ ] 亮底场景没有泛光糊白；文字没有出框、没有互相重叠
- [ ] 字幕与画面文字不重复堆叠
- [ ] 转场处（前后 0.5 秒）抽帧看过
- [ ] 爆点处声画同步：冲击声与画面同一帧
- [ ] 全片响度 −16 LUFS 左右，峰值 < −1dB
- [ ] 事实都有来源，推演部分有明确标注
- [ ] 戴耳机完整看一遍
